SB Host Switched

Host and Sandbox Layout

The privileged host builds the filesystem view. Its VFS root is a ROMFS image containing the web content, with a streams driver mounted on /dev.

The host assigns sandbox 2 a separate VFS root referencing the same ROMFS and streams drivers. Its current directory and path-resolution state are therefore private, while the immutable filesystem content remains shared. Inside the sandbox, the POSIX syscalls map open, read, fstat and directory operations onto that root.

The HTTP server itself remains unaware of the host-side VFS details. It just uses the POSIX binding hooks required by lwIP HTTPD custom files.
