*****************************************************************************
*** Generated manuals                                                     ***
*****************************************************************************

The content of this directory is generated, it is not part of the
repository and it is ignored by git.

Each manual is built in its own subdirectory by the makehtml.sh (or
makehtml.bat, makechm.bat) script in the corresponding doc/build/<manual>
directory, for example:

  cd doc/build/rt
  ./makehtml.sh

Doxygen does not create this directory, this file keeps it in the
repository. The index of the manuals is doc/manuals/index.html.
